Installation Guide

Step 1: Download the Extension

Open this GitHub repository.

Click Code → Download ZIP.

Extract the downloaded ZIP archive to a folder on your computer.

Keep the extracted folder in a permanent location. Do not delete or move it after installation.

Step 2: Enable Developer Mode

Open Google Chrome.

Enter the following address in the address bar:

chrome://extensions/

Press Enter.

Enable Developer mode using the toggle in the top-right corner.

Step 3: Load the Extension

Click Load unpacked.

Navigate to the folder where you extracted Kundelik Plus.

Select the folder containing manifest.json directly.

Click Select Folder.

Kundelik Plus should now appear on the Chrome extensions page.

Step 4: Pin the Extension

Click the Extensions icon (puzzle piece) in the Chrome toolbar.

Find Kundelik Plus.

Click the pin icon next to it.

The extension icon should now appear in your toolbar.
